# Remote notes (what the frame can't show)

- Home: OK plays the focused tile straight away. Hold OK toggles favourite. Down moves to the next row; Up from the first row goes to the tabs. The hero follows focus. While the guide loads, OK still plays the channel.
- Player overlay: OK or Down shows it; it hides after 5 s or on Back. Up/Down change channel even when hidden. Left rewinds (catch-up channels only, else "This stream can't rewind."). Right opens What else is on.
- What else is on: OK switches and closes the panel. Back closes without switching. Favourites are listed first.
- Audio & subtitles: OK picks and keeps the sheet open, so you can choose both. Back closes.
- Message: Retry gets focus first. "Reconnecting…" needs no input and clears itself; "Starting catch-up…" likewise.
- Guide: Left/Right move in time, Up/Down change channel, OK plays now or plays catch-up from the start. Up from the top row goes to the filters. Jump to now returns focus to the live cell on the same channel. Hold OK on a channel name toggles favourite.
- What's on now: Up from Live now goes to the groups; Left/Right then changes group. The "more" tile opens the full shelf. Hold OK to favourite.
- Search: results update as you type. Hold Mic anywhere on the screen to speak. Right from the keyboard moves into the results.
- Settings: Left/Right on Guide offset changes it in 5 min steps; the sentence updates. OK on a source opens it (Refresh, Edit, Remove).
- Setup: OK on a field opens the system keyboard. Down moves box to box. The phone address stays live while this screen is open.
- How Porch works: OK on Got it returns to Home. Shown once on first launch; later from Settings.
